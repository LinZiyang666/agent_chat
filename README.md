agentchat
=========

A small CLI over Discord for personal use.

Install
-------

    curl -fsSL https://github.com/LinZiyang666/agent_chat/releases/latest/download/install.sh | sh

Binaries land in `~/.agentchat/bin`. Data lives in `~/.agentchat`.

Build from source
-----------------

    make build

Requires Go 1.25+. Produces `bin/agentchat` and `bin/agentchatd`.
